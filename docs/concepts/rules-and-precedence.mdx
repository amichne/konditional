---
title: "Rules and precedence"
---

A rule pairs targeting criteria with a value. A typed fact comparison contributes one unit of specificity.
`allOf` adds its children's scores. `anyOf` takes the highest child score.
The context determines whether the expression matches. Its score depends only on its structure.

The engine considers rules in descending order of targeting specificity. For each match, the engine checks rollout eligibility. A rule that misses its rollout does not prevent a later rule from matching.

The first eligible match supplies the value. If no rule qualifies, evaluation returns the feature default. Use [`explain`](/reference/evaluation-diagnostics) to see the decision for a specific context.
