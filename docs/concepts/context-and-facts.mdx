title: "Context and facts"

A `Context` supplies the inputs that a feature can inspect.

## Declare facts for your domain

A fact declares its value type and stable identifier. A namespace lists the facts its rules can use.
Each evaluation context supplies the values for one decision.

For example, a warehouse can accept a delivery when its zone is cold storage and its temperature is at most four degrees Celsius.

```kotlin
import io.amichne.konditional.api.evaluate
import io.amichne.konditional.context.Context
import io.amichne.konditional.context.fact.*
import io.amichne.konditional.core.Namespace
import io.amichne.konditional.core.result.ParseError
import io.amichne.konditional.core.result.ParseResult

enum class Zone { COLD_STORAGE, LOADING_DOCK }
@JvmInline value class Celsius(val degrees: Int)

val zone = SingleFact("warehouse.zone", FactDomain.enumeration(Zone.entries) { it.name })
val temperature = OrderedFact(
    "warehouse.celsius",
    FactDomain<Celsius>(
        encode = { it.degrees.toString() },
        decode = { raw ->
            raw.toIntOrNull()?.let { ParseResult.Success(Celsius(it)) }
                ?: ParseResult.Failure(ParseError.invalidValue("warehouse.celsius", "Expected whole degrees"))
        },
    ),
    compareBy(Celsius::degrees),
)

object Warehouse : Namespace("warehouse", factSchema = FactSchema(zone, temperature)) {
    val acceptDelivery by boolean<Context>(default = false) {
        rule(true, allOf(zone.oneOf(Zone.COLD_STORAGE), temperature.atMost(Celsius(4))))
    }
}

data class Reading(val location: Zone, val measured: Celsius) : Context {
    override val facts = Facts.of(zone.value(location), temperature.value(measured))
}

fun accept(location: Zone, measured: Celsius): Boolean =
    Warehouse.acceptDelivery.evaluate(Reading(location, measured))
```

`SingleFact` accepts one value. Use `MultiFact` for a set, such as an operator's qualifications.
Its `oneOf` condition matches when the supplied set contains an allowed value.
`OrderedFact` also supports inclusive `atLeast` and `atMost` comparisons.
An absent fact makes a comparison miss.

Snapshot export uses each fact's identifier and encoded operands. Keep both stable across applications that exchange rules.
Supply a deterministic comparator and a decoder that accepts each value the encoder produces.

## Stable identifiers and rollout

Implement `Context.StableIdContext` for a gradual rollout. The engine uses the stable ID, feature key, and salt to calculate the bucket.
