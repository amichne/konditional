---
title: "Add the engine to your project"
description: "These steps use a local copy of Konditional with a Kotlin/JVM Gradle project."
---

Use JDK 27. The Konditional build uses Gradle 9.8.2 and Kotlin 2.4.21.

1. From the directory that contains your application project, clone Konditional
   alongside it.

    ```sh
    git clone https://github.com/amichne/konditional.git
    ```

2. In your application's `settings.gradle.kts`, include the checkout.

    ```kotlin
    includeBuild("../konditional")
    ```

3. In the application module's `build.gradle.kts`, add the engine dependency.
   Use Maven Central for its dependencies. The included build supplies the
   engine itself.

    ```kotlin
    kotlin {
        jvmToolchain(27)
    }

    java {
        targetCompatibility = JavaVersion.VERSION_26
    }

    dependencies {
        implementation("io.github.amichne:konditional-engine")
    }
    ```

Reload the Gradle project in your IDE.

<Accordion title="Where does Gradle get the engine?">
  The included build supplies `konditional-engine` from your checkout. Maven Central supplies its external dependencies. To try the versioned artifacts in a separate application, see [Set up a standalone checkout application](/guides/standalone-checkout).
</Accordion>

[Run your first flag](/quickstart#declare-the-flag) in this module to check that an iOS device gets the new checkout.
