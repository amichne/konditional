---
title: "Load JSON safely"
---

For the [standalone application](/guides/standalone-checkout#add-json-support), add the versioned JSON dependency. If your application uses the [included build](/quickstart/install), add `implementation("io.github.amichne:konditional-json")`. Use the [eligibility namespace](/quickstart/define-first-namespace) for this check. Create `src/main/kotlin/Snapshots.kt`.

Export the checkout configuration with `toJson()`. On import, `fromJson` loads the decoded configuration or returns a typed error. A failed import keeps the active configuration.

```kotlin
import io.amichne.konditional.core.result.ParseResult
import io.amichne.konditional.serialization.fromJson
import io.amichne.konditional.serialization.toJson

fun checkSnapshots() {
    val json = EligibilityFlags.toJson()
    val loaded = EligibilityFlags.fromJson(json)
    check(loaded is ParseResult.Success)
    check(EligibilityFlags.toJson() == json)

    val before = EligibilityFlags.currentSnapshot
    val rejected = EligibilityFlags.fromJson("{ not-json")
    check(rejected is ParseResult.Failure)
    check(EligibilityFlags.currentSnapshot == before)
}
```
