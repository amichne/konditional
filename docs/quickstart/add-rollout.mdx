---
title: "Gradual rollout"
---

Enable the checkout upsell for 25% of rollout buckets. The engine calculates each bucket from the salt, feature key, and stable ID. Two namespaces with the same three inputs assign the same bucket.

Create `src/main/kotlin/Rollout.kt`. Give each user a stable ID so that repeated requests get the same bucket.

```kotlin
import io.amichne.konditional.api.explain
import io.amichne.konditional.context.Context
import io.amichne.konditional.context.Rollout
import io.amichne.konditional.context.fact.NoFacts
import io.amichne.konditional.core.Namespace
import io.amichne.konditional.core.dsl.enable
import io.amichne.konditional.core.id.StableId

data class RolloutContext(override val stableId: StableId) : Context.StableIdContext

object RolloutFlags : Namespace<NoFacts>("rollout", NoFacts) {
    val checkoutUpsell by boolean<RolloutContext>(default = false) {
        enable(rollout = Rollout.of(25))
    }
}

fun checkRollout() {
    val context = RolloutContext(StableId.of("same-user"))
    val first = RolloutFlags.checkoutUpsell.explain(context)
    val second = RolloutFlags.checkoutUpsell.explain(context)
    check(first.value == second.value)
    check(first.decision == second.decision)
}
```

This namespace reads no facts, so it uses `NoFacts`. `enable` takes no condition and applies to every context inside the rollout.
To combine a condition with a rollout, pass both: `enableWhen(rollout = Rollout.of(25)) { channel.oneOf(Channel.PILOT) }`.

The decision includes the bucket for a matched rule or a rule skipped by rollout.

To interpret the bucket for one user, see [Evaluation diagnostics](/reference/evaluation-diagnostics#rule-matches).
