## Declaration and evaluation

Call `evaluate` on the feature property. Its context and return type come from the namespace declaration.

Using the flag from [Run your first flag](/quickstart) gives a Boolean result.

```kotlin
val showNewCheckout = CheckoutFlags.newCheckout
    .evaluate(Account(Channel.PILOT))
```

| API | Purpose |
| --- | --- |
| `Namespace<S>` | Owns feature declarations, namespace identity, the fact schema `S`, and runtime registry access |
| `Feature<T, C, M>` | Typed handle bound to a value type, context type, and namespace |
| `boolean`, `string`, `integer`, `double`, `enum`, `custom` | Namespace delegates for declaring features |
| `evaluate(context)` | Returns the typed feature value for the given context |
| `explain(context)` | Returns the evaluation result plus diagnostics for the same decision path |

## Context and targeting

| API | Purpose |
| --- | --- |
| `Context` | Base evaluation input |
| `FactSchema` | Base class for a namespace's facts; `single`, `multi`, and `ordered` declare them |
| `NoFacts` | Schema for a namespace whose rules read no facts |
| `SingleFact<T>`, `MultiFact<T>`, `OrderedFact<T>` | A declared fact's value domain and supported comparisons |
| `oneOf`, `noneOf`, `atLeast`, `atMost` | Build one portable comparison on a fact |
| `Facts.of(...)` | Supplies typed fact values on a context |
| `Condition<S>` | A reusable function from a schema, or an interface it implements, to one expression |
| `allOf(...)`, `anyOf(...)`, `not(...)` | Combine expressions or conditions. `allOf` and `anyOf` reject an empty group |
| `named(label, ...)` | Attaches a domain name that explanations and snapshots carry |
| `Context.StableIdContext` | Opt-in stable identity for rollout and allowlists |
| `Rollout` | Rollout percentage; `Rollout.of(25)` |

## Rules

Each form takes `rollout`, `note`, and `allowlist` as optional arguments.

| API | Purpose |
| --- | --- |
| `rule(value, condition)`, `rule(value) { ... }` | Yields the value when the context satisfies the condition |
| `always(value)` | Yields the value for every context inside the rollout |
| `enableWhen`, `disableWhen` | Boolean forms of `rule` |
| `enable`, `disable` | Boolean forms of `always` |
| `ruleResolved`, `alwaysResolved` | Compute the value from the context after the rule matches. A snapshot cannot carry these rules |

## Runtime state

| API | Purpose |
| --- | --- |
| `Configuration` | Runtime flag map plus metadata |
| `ConfigurationMetadata` | Optional version, source, and generation timestamp |
| `NamespaceRegistry` | Load, rollback, disable, enable, and flag lookup contract |
| `InMemoryNamespaceRegistry` | Default in-memory registry with atomic snapshot replacement |

## JSON import and export

| API | Purpose |
| --- | --- |
| `Konstrained` | Contract for custom values that can round-trip through the JSON layer |
| `Namespace.toJson()` | Export the current namespace snapshot |
| `Namespace.fromJson(json)` | Strictly decode a snapshot and load it on success |
| `ParseResult.Success` / `ParseResult.Failure` | Typed success or failure from snapshot import |
| `ParseError` | Structured failure model for JSON decoding errors |

## Diagnostics

| API | Purpose |
| --- | --- |
| `EvaluationDiagnostics<T>` | Snapshot of one evaluation result and its decision path |
| `EvaluationDiagnostics.Decision` | Closed set of evaluation outcomes |
| `EvaluationDiagnostics.RuleMatch` | Matched rule details plus bucket metadata |
| `BucketInfo` | Deterministic rollout bucket metadata for the matched rule |
