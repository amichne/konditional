---
title: "Snapshot JSON format"
---

`Namespace.toJson()` exports a versioned envelope. The `snapshot` object holds the flags and optional metadata.
The receiving namespace supplies the fact schema.

## Top-level shape

This snapshot describes one Boolean feature from the [warehouse example](/concepts/context-and-facts).

```json
{
  "format": "konditional/facts-v1",
  "snapshot": {
    "flags": [{
      "key": "feature::warehouse::acceptDelivery",
      "defaultValue": { "type": "BOOLEAN", "value": false },
      "rules": [{
        "value": { "type": "BOOLEAN", "value": true },
        "conditions": [{
          "all": [
            { "oneOf": { "fact": "warehouse.zone", "operands": ["COLD_STORAGE"] } },
            { "atMost": { "fact": "warehouse.celsius", "operand": "4" } }
          ]
        }]
      }]
    }]
  }
}
```

The optional `meta` object accepts `version`, `generatedAtEpochMillis`, and `source`.
Use `konditional/facts-v1` for the format identifier.

## Flag entries

Each entry in `flags` represents one feature definition for the namespace.

| Field | Meaning |
| --- | --- |
| `key` | Serialized `FeatureId` |
| `defaultValue` | Typed value envelope for the flag's default |
| `salt` | Stable bucketing salt |
| `isActive` | Whether the flag is active |
| `rampUpAllowlist` | Stable IDs that bypass ramp-up gating |
| `rules` | Serialized rule list in snapshot order |

## Value envelope shapes

`defaultValue` and rule `value` fields use a typed envelope.
For each default and static rule, the envelope must match the feature's declared value type.

| `type` | Additional fields |
| --- | --- |
| `BOOLEAN` | `value: true` or `false` |
| `STRING` | `value: "..."` |
| `INT` | `value: 42` |
| `DOUBLE` | `value: 42.5` |
| `ENUM` | `value`, `enumClassName` |
| `DATA_CLASS` | `value`, `dataClassName` |
| `KONSTRAINED_PRIMITIVE` | `value`, `konstrainedClassName` |

## Rule entries

Each rule entry can carry these fields.

| Field | Meaning |
| --- | --- |
| `value` | Typed envelope for the rule value |
| `ruleId` | Optional serialized rule identifier |
| `rampUp` | Rollout percentage as a `Double` |
| `rampUpAllowlist` | Stable IDs that bypass rule ramp-up gating |
| `note` | Optional human note |
| `conditions` | Required ordered array of expressions. Every condition must match. An empty array matches any context. |

Snapshot rules contain static values and portable fact expressions.
If a rule uses a Kotlin predicate or a contextual value resolver, `toJson()` throws `KonditionalBoundaryFailure` with `ParseError.InvalidSnapshot`.
The error identifies the feature and rule.

## Portable fact expressions

`all` and `anyOf` contain ordered arrays of expressions.
`oneOf` accepts a list of operands. Each inclusive comparison, `atLeast` or `atMost`, accepts one operand.
The receiving namespace resolves each fact identifier and parses its operands in that fact's domain.
An unknown fact, unsupported comparison, or invalid operand rejects the entire import.
