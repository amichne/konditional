---
title: "Tests for a namespace"
---

Define a small namespace and contexts with known inputs. Cover each behavior that the application uses.

| Behavior | Assertion |
| --- | --- |
| Targeting | A matching context gets the rule value. An unmatched context gets the default. |
| Rollout | Repeated calls with the same inputs produce the same decision and bucket. |
| Namespace isolation | Two namespaces can declare the same key and return different values. |
| JSON rejection | A malformed or mismatched payload returns a failure and preserves the active snapshot. |
| Concurrent updates | Each reader sees one complete snapshot during a load or rollback. |

The [standalone checkout example](/quickstart/verify-behavior) includes runnable assertions. For concurrent readers and writers, see [`NamespaceAtomicityTest`](https://github.com/amichne/konditional/blob/main/konditional-engine/src/test/kotlin/io/amichne/konditional/runtime/NamespaceAtomicityTest.kt).
