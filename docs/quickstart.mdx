Use the Kotlin/JVM module from [Add the engine to your project](/quickstart/install).

## Declare the flag

Create `src/main/kotlin/Checkout.kt` in your application module. A fact schema
declares the inputs that rules can read. Here, `AccountFacts` declares the release channel, and the account supplies its value.
A namespace groups related flags and names the schema they use.

```kotlin
import io.amichne.konditional.api.evaluate
import io.amichne.konditional.context.Context
import io.amichne.konditional.context.fact.FactDomain
import io.amichne.konditional.context.fact.FactSchema
import io.amichne.konditional.context.fact.Facts
import io.amichne.konditional.core.Namespace
import io.amichne.konditional.core.dsl.enableWhen

enum class Channel { PILOT, GENERAL }

object AccountFacts : FactSchema() {
    val channel = single("account.channel", FactDomain.enumeration(Channel.entries) { it.name })
}

data class Account(val releaseChannel: Channel) : Context {
    override val facts = Facts.of(AccountFacts.channel.value(releaseChannel))
}

object CheckoutFlags : Namespace<AccountFacts>("checkout", AccountFacts) {
    val newCheckout by boolean<Account>(default = false) {
        enableWhen { channel.oneOf(Channel.PILOT) }
    }
}
```

Inside `enableWhen`, `channel` is the fact that `AccountFacts` declares.

## Evaluate it

Add this function to the same file. Run `main()` from your IDE.

```kotlin
fun main() {
    for (releaseChannel in Channel.entries) {
        val showNewCheckout = CheckoutFlags.newCheckout
            .evaluate(Account(releaseChannel))
        println("$releaseChannel: $showNewCheckout")
    }
}
```

```text
PILOT: true
GENERAL: false
```

The pilot account matches the rule. The general account gets the default.
