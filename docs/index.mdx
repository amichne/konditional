Should this account see the new checkout? Give the flag a default of `false` and a rule that enables it for pilot accounts. The caller gets a Kotlin `Boolean` it can use directly.

```kotlin
val showNewCheckout = CheckoutFlags.newCheckout
    .evaluate(Account(Channel.PILOT))  // true
```
