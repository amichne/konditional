# Konditional

Konditional is a feature-flag library for Kotlin. Declare a flag with a default
value and a rule. At the call site, pass the input the rule needs and get back
the flag's Kotlin value.

In the quickstart, one rule enables a new checkout on iOS while Android keeps
the default. [Run your first flag](quickstart/index.md).

If you already have a working flag, choose a task from
[Advanced usage](guides/index.md).
