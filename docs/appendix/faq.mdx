## Which applications can use Konditional?

The library targets Kotlin/JVM applications. [Install Konditional](/quickstart/install) lists the toolchain.

## Who operates the control plane?

The application supplies its own operator tools and remote configuration delivery. Konditional evaluates the rules locally.

## Do I need JSON for code-defined features?

No. Declare a namespace with `konditional-engine` and call `evaluate`. Add `konditional-json` when you need snapshot import or export.

## Can a feature return a structured value?

Yes. Use `custom<T, C>` with a type that implements `Konstrained`. See [custom values](/guides/custom-konstrained-values) for an object with a schema.
