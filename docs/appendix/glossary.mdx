---
title: "Glossary"
---

| Term | Meaning |
| --- | --- |
| namespace | A group of declared features with an identifier and a registry. |
| feature | A typed handle that belongs to one namespace and accepts a specific context type. |
| context | The input a caller supplies to evaluate a feature. |
| axis | A targeting dimension with a defined set of values. |
| axis value | An enum entry that identifies one value on an axis. |
| rule | Criteria that determine when a feature can return an associated value. |
| ramp-up | A percentage threshold that controls which rollout buckets qualify for a rule. |
| configuration | A map of feature definitions and their metadata. |
| namespace registry | The component that stores namespace snapshots and handles load, rollback, disable, and enable operations. |
| parse result | The success or failure returned by snapshot import. |
| parse error | A typed reason for a failed parse. |
| Konstrained | The Kotlin contract for a custom feature value with a supported wire representation. |
